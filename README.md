# Arduino-diorama

Simple Arduino projects for model train layouts and dioramas. They are small, easy to build and meant to be dropped into a layout: random room lighting, flickering fluorescent tubes, welding lights and similar effects. Each project has its own folder with the sketch, the Wokwi circuit (`diagram.json`) and a short README.

The circuits can be simulated in the browser on [Wokwi](https://wokwi.com) before building them.

## Projects

| Project | Description | Wokwi |
|---|---|---|
| [16led-shift-register](16led-shift-register/) | 16 LEDs on two chained 74HC595 shift registers with random lighting patterns and a potentiometer for the speed | [Open](https://wokwi.com/projects/364879086655198209) |
| [rgb-led-welding](rgb-led-welding/) | Welding effect with one RGB LED: blue-white flashes, sometimes followed by glowing melting steel | [Open](https://wokwi.com/projects/365253880279768065) |
